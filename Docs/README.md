# Sakura Tactics Prototype Documentation

This directory is the durable record for the Unreal Engine prototype created during the August 2026 evaluation.

## Documents

- [CONVERSATION_SUMMARY.md](CONVERSATION_SUMMARY.md) — chronological, sanitized summary of the research, implementation, failures, corrections, and current direction.
- [STACK.md](STACK.md) — technical authority boundaries, runtime architecture, test procedures, limitations, and redistribution notes.
- [../README.md](../README.md) — quick-start instructions and current controls.

## Source of truth

When documents disagree, use this order:

1. Aurora's latest explicit requirement.
2. Current source and project configuration.
3. `STACK.md` for technical architecture.
4. `CONVERSATION_SUMMARY.md` for historical context.

The summary intentionally records unsuccessful approaches so they are not repeated. It contains no API keys, authentication codes, email addresses, or other credentials.
